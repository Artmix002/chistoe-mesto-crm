# Расширение Chrome для заказов Авито

Расширение читает заказы только на `www.avito.ru/orders` и отправляет их в локальную CRM на `127.0.0.1:47621`.

Установка на macOS и Windows:

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение».
4. Выберите эту папку.
5. Откройте заказы Авито в том же профиле Chrome.

Расширение не передаёт логины, cookies или пароли.
